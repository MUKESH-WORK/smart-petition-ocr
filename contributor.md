# Contributors

Thank you to everyone who has contributed to **GDP Assistant** — the AI-powered grievance redressal platform for Tamil Nadu District Administration.

## How to Contribute

Please refer to the comprehensive [CONTRIBUTING.md](CONTRIBUTING.md) guide for instructions on:
- Development environment setup
- Coding standards (Python backend & React frontend)
- Branching and commit message conventions
- Dynamic translation guidelines (LLM-powered, no hardcoded strings)
- Intake channel contribution workflow
- Pull request procedures and review process
